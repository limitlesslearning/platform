# Klados platform

The Klados platform — free, open-source global knowledge graph with mastery-based learning and verifiable credentials.

This repository will hold the product application (planned: SurrealDB · ElysiaJS · Tauri · Svelte). Documentation lives in [`docs`](https://github.com/limitlesslearning/docs) ([live site](https://limitlesslearning.github.io/docs/)).

## Web app (Phase 1)

The SvelteKit web app lives in [`apps/web`](./apps/web/). It currently holds UI-only design screens for the Phase 1 MVP (core learning loop, learner home, reviews). See [apps/web/README.md](./apps/web/README.md) to run it.

## Brand

Logo files are in [`assets/brand/`](./assets/brand/). How to use them: [docs/brand/USAGE.md](./docs/brand/USAGE.md).
